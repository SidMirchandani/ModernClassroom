# ADR-010: Curriculum modelled as sections with parallel resource tracks
Status: Accepted
Date: 2026-11-02
Recorded: retroactively

## Context
- Per the master doc: the course runs off three resources (textbook, AP Classroom, guided notes) that cover the same objectives in different orders and can't share one numbering.

## Options considered
- OPEN: not stated (v2.0 "Rebuild Curriculum Around Resource Tracks" replaced an earlier flat model).

## Decision
- Class → Unit → Section → ResourceTrack (Learn → Practice), with stable track ids (`"3.1::textbook"`).

## Tradeoffs accepted
- OPEN: not stated.

## Revisit if
- OPEN: not stated.
